# ChatAI

Управляй миром Minecraft из чата: пишешь `AI <желание>` — мод выполняет.

> **Важно:** встроенный разбор — это *правила и словарь* (русский и английский), а не нейросеть.
> Он работает без интернета. Настоящий ИИ подключается только если ты сам включишь Claude API и вставишь ключ.

## Статус версий (честно)

| Версия | Исходники | Собрано и проверено в игре |
|---|---|---|
| Forge 1.20.1 | готовы (`versions/forge-1.20.1`) | **нет** — код не компилировался (см. ниже) |
| Forge 1.21.11 | не написаны | нет |
| Forge 26.2 | не написаны | нет |
| Forge 26.3 | не написаны | нет |

Общее ядро `core/` (разбор запросов, лимиты, сообщения, шаблоны построек) скомпилировано и
проходит 36 автотестов (`ParserSelfTest`). Код под Forge 1.20.1 не компилировался, потому что в среде
разработки нет доступа к maven Forge, поэтому возможны мелкие ошибки компиляции — их покажет первая
сборка в GitHub Actions. Версии 1.21.11 / 26.2 / 26.3 требуют отдельной адаптации API (в 26.x GUI
переписан на retained-mode, Java 25) и пока не сделаны.

## Что умеет

`AI дай мне 64 алмаза`, `AI дай игроку Steve 20 золотых яблок`, `AI построй башню`, `AI сделай ночь`,
`AI начни дождь`, `AI дай мне эффект скорости на 2 минуты`, `AI создай много овец`,
`AI телепортируй меня к игроку Steve`, `AI вылечи меня`, `AI создай праздничный фейерверк`
(и английские варианты). Постройки: дом, башня, замок, мост, пирамида, платформа.
Крупные изменения требуют `AI подтверди` / `AI confirm` (30 с), отмена — `AI отмена`.

## Безопасность

- Все изменения делает сервер; клиент ничего не меняет сам.
- Права: отдельные уровни для своих действий, чужих игроков, погоды/времени, построек (`chatai-common.toml`).
- Кулдаун, лимит действий на запрос, не больше 100 существ за раз, защита спавна (`mayInteract`).
- Постройка сначала проверяется целиком и только потом ставится.
- Из текста не выполняется никакой код; ответ внешнего API проверяется по жёсткой схеме.
- При включённом API текст запроса отправляется провайдеру; ключ лежит в конфиге открытым текстом.

## Настройки

`/chatai` (клиент) или кнопка Config в списке модов открывает **ChatAI Settings**.
GUI меняет конфиг на этой машине. На выделенном сервере настройки берутся из
`config/chatai-common.toml` **на сервере** — правь файл.

## Сборка

Каждая версия — отдельный Gradle-проект в `versions/`.

**GitHub Actions (рекомендуется):** залей папку в репозиторий, вкладка Actions → Build ChatAI →
артефакт `ChatAI-forge-1.20.1` с jar.

**Локально (1.20.1):** JDK 17 и Gradle 8.1.1:
```
cd versions/forge-1.20.1
gradle build
```
Jar появится в `build/libs/`.

## Установка

Положи jar в `mods/` клиента (и сервера). Нужен Forge 47.x для Minecraft 1.20.1.
Мод можно поставить только на сервер: тогда `AI ...` работает, а GUI настроек недоступен.
